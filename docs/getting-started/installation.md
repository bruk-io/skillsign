# Installation

## Requirements

- Python 3.14+
- A GitHub account (for signing)

## Install via pip

```bash
pip install skillsign
```

## Install via Homebrew

```bash
brew install bruk-io/tap/skillsign
```

## Run without installing (uvx)

```bash
uvx skillsign sign ./SKILL.md
```

## Verify installation

```bash
skillsign --version
```
